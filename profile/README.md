## OCTAL ARP

**Eight arpeggiators. Endless possibilities.**

An eight-layer MIDI arpeggiator for **Logic Pro on macOS**. Turn the chords you play into interlocking rhythms and melodies, using your own software instruments for the sound.

<p>
  <img src="https://raw.githubusercontent.com/Airutrance/.github/main/octal-arp.png" alt="OCTAL ARP showing its eight layers, rhythm controls and twelve Live Presets in the SRM Live colour theme" width="800">
</p>

- **Shape eight independent parts.** Give each layer its own rhythm, note movement, timing and dynamics.
- **Build your arrangement.** Save twelve Live Presets and automate changes between them in Logic.
- **Perform your variations.** Switch Live Presets as you play or record, with changes synchronized to the bar while Logic is running.

OCTAL ARP will be **free and open source**. The first public release is in preparation; download and user manual links will appear here when it is available.
